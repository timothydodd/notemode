**NoteMode** is a free, open-source text editor for Windows (also runs on macOS and Linux from source) that remembers your session: every tab, including unsaved edits, is still there after you close it or restart your PC. It also has notes that don't need a file, search across tabs and folders, syntax highlighting for 30+ languages and a Markdown preview.

![NoteMode](https://raw.githubusercontent.com/timothydodd/notemode/main/docs/store/screenshots/01-session.png)

## What's new in 0.3.1

- **Code-signed.** The installer, `NoteMode.exe` and everything in the zip are now signed by Timothy Stephen Dodd (Microsoft Artifact Signing), so Windows shows a verified publisher instead of "Unknown publisher" and SmartScreen stops blocking the download.

The app itself is the same as 0.3.0. If you're coming from 0.2.x, see the [0.3.0 release notes](https://github.com/timothydodd/notemode/releases/tag/v0.3.0) for everything that changed: safe saves, kept encodings, protected unsaved edits, the new installer and more.
