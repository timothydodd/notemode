**NoteMode** is a free, open-source text editor for Windows (also runs on macOS and Linux from source) that remembers your session: every tab, including unsaved edits, is still there after you close it or restart your PC. It also has notes that don't need a file, search across tabs and folders, syntax highlighting for 30+ languages and a Markdown preview.

## What's new in 0.3.0

A hardening release: NoteMode should never lose anything you typed.

### Your text is safer
- **Safe saves.** A file is replaced only once the new version is fully written, so a crash or a full disk can't leave a half-written file.
- **Failed saves are reported.** Saving to a read-only or locked file now shows an error and keeps your edits open. Previously the save failed silently, and closing the tab lost the edits.
- **Encodings are kept.** Files are saved the way they were opened (UTF-8 with or without BOM, UTF-16, legacy ANSI/Windows-1252) instead of always as UTF-8, so accented characters in older files no longer get mangled. The status bar shows the encoding.
- **Restored tabs are protected.** After a restart, tabs you haven't clicked on yet still count as unsaved if they hold cached edits, so closing them, "Close Unchanged", or the file changing on disk can't discard them.
- **Safer dialogs.** Closing the "Save changes?" or "File changed on disk" dialog with its X now cancels or keeps your version, instead of saving or reloading. Esc works in every dialog.
- **Edits survive exit and crashes.** Pending edits are written to disk when you close the window and on an unexpected error (logged to `~/.notemode/error.log`). Edits in a file opened by double-clicking it are kept too.
- The "file changed on disk" prompt no longer opens again every few seconds while it's showing.

### Improvements
- New Windows installer: Start menu shortcut, NoteMode under "Open with", optional "Edit with NoteMode" in the Explorer context menu, and an optional desktop shortcut. It **removes an older MSI install for you**; your tabs and notes are kept.
- Edit menu: Cut, Copy, Paste and Select All. Tab menu: Copy Path and Reveal in File Explorer.
- Ctrl+F / Ctrl+H reopen the same Find window instead of stacking new ones; Ctrl+H focuses the Replace box.
- Settings shows the version and a link to this project.
- Opening a file from a terminal with a relative path (`NoteMode notes.txt`) works while NoteMode is already running.
- The maximize button turns into a restore button when maximized; icon buttons have tooltips.
- Light theme fixes (loading overlay, search highlights) and consistent panel headers.
- Markdown preview no longer crashes on Linux and macOS.
- Updated to Avalonia 12.1.3.
