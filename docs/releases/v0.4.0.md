**NoteMode** is a free, open-source text editor for Windows (also runs on macOS and Linux from source) that remembers your session: every tab, including unsaved edits, is still there after you close it or restart your PC. It also has notes that don't need a file, search across tabs and folders, syntax highlighting for 30+ languages and a Markdown preview.

## What's new in 0.4.0

### Tail log files
- `.log` files get a **Tail** button in the status bar. While it's on, NoteMode follows the file as another program writes to it: it checks the file every second, shows the new lines and keeps the view scrolled to the end.
- A tailed tab is read-only, so nothing you type can get mixed up with the reloads. Turn Tail off to edit again. (Tail can't be turned on while the tab has unsaved edits, because it reloads the file.)
- Tailing is remembered: a log you were tailing is still tailing after you restart NoteMode.

### A cleaner look
- **Darker editor** in the Dracula theme, with the title bar, tab strip and editor each a different shade so they're easy to tell apart.
- **The active tab** now has the same background as the text, and the colored line under it is gone.
- **Note tabs** are marked with a yellow line down their left edge instead of along the bottom.
- **Line numbers** sit closer to the left edge, and the dotted line between the numbers and the text is gone. Text now lines up exactly with its line number (it used to sit slightly lower).
- **Menus** no longer show icons next to each command.
