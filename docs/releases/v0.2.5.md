**NoteMode** is a free, open-source text editor that remembers your session: every tab, including unsaved edits, is still there after you close it or restart your PC.

## What's new in 0.2.5
- **Fix:** the window could not be resized after the Avalonia 12 upgrade in 0.2.4 (the resize border had been removed along with the title bar).

## Also in 0.2.4
- **Single window:** opening a file while NoteMode is running adds a tab to the open window instead of starting a second copy.
- **Large files:** a loading overlay instead of a frozen window, and files with very long lines no longer slow the editor to a crawl.
- **Markdown:** task lists (`- [ ]` / `- [x]`) render as checkboxes in the preview.
- The status bar shows the file size; the window always opens centered.
- Updated to Avalonia 12.
